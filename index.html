This is an interpreter, not a game. It needs the data files from a copy of a game that you own. Eight engine families are recognised, and the files decide which one answers — you are never asked to pick.

Supported Engines
  • LucasArts SCUMM — all seven Versions, v2 through v8.
  • Sierra AGI — both packaging majors, v2 and v3, over the six interpreter builds this project tells apart.
  • Sierra SCI — all thirteen Versions, SCI0 early through SCI3. A game reaches its own dialog loop and runs it; the interface those scripts draw is not drawn here yet, so there is nothing on screen to answer.
  • Adventure Soft AGOS — all seven of its Versions, each named after its game rather than numbered: Elvira 1, Elvira 2, Waxworks, Simon 1, Simon 2, The Feeble Files and the Puzzle Pack. AGOS keeps its font in the original interpreter executable, so game data alone draws no text.
  • Revolution’s Sky — all three Releases of Beneath a Steel Sky: the demo, the floppy and the CD. It reaches a room and runs the game’s scripts; nothing plays through yet, and it says where it stopped rather than showing you a black screen.
  • Revolution’s Lure — both Releases of Lure of the Temptress, the demo and the floppy. It reads the game and the world state a new game starts from, and its own bytecode is a separate system this project does not run yet.
  • Revolution’s Broken Sword — all three Releases of Broken Sword: The Shadow of the Templars, the demo, the CD game and the PlayStation conversion. It runs the game’s scripts, walks George, draws its rooms and speaks its lines; it skips the cutscenes, and it says so rather than stopping.
  • Revolution’s Broken Sword II — all three Releases of The Smoking Mirror. A separate engine from the first game rather than a later version of it: they share no bytecode and no file format. It runs, draws and edits; its walk-finding is separate work from the first game’s, so nobody walks yet and the status line leads with that.

Loose files, a whole folder or a single .zip all work. Anything else is named and refused rather than half-run.

Nothing is uploaded. The files are read in your browser and stay on your machine.

Dragging is never required: “Open game folder…” and “Open files…” in the bar above do the same thing with a single click or the Enter key.
